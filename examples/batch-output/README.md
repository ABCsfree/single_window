# 批量输出示例

更新后的生成器会为整批输出：

- `ELBP004_<流水号>_<时间戳>.xml`：整批唯一的信息补录主报文，包含全部箱号项及附件元数据。
- `<箱号>_<业务类型>_<时间戳>.xml`：每个箱号按批量界面选择生成 3、4 或 5 份随附单据报文。
  - 3 张：`A1`、`A2`、`A3`
  - 4 张：`A1`、`A2`、`A3`、`A4`
  - 5 张：`A1`、`A2`、`A3`、`A4`、`B1`
- 启用 P0 时另有整批唯一的 `0_P0_<时间戳>.xml`。

`ELBP004` 与对应 `ELBP005` 使用相同的 `EdocID`。其格式为“出口企业 18 位统一社会信用代码 + 4 位主管海关代码 + 附件代码 + `yyyyMMddHHmmssfff` + 20 位流水号”，总长度不超过 64 位（A1/P0 等 2 位附件代码时为 61 位）。实际 XML 可通过应用生成，避免示例中的签名、时间和流水号被误当成固定值。
